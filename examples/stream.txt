Notes
-----

* start MUST be first; exactly one done or one error MUST be last.
* Concatenating every delta.text in order equals done's output.value.
  In this example: "## Positioning brief\n\n" + "The mid-market segment is
  served by three incumbents…" — which is exactly output.value.
* step and delta are both OPTIONAL and may appear zero or more times. A
  Level 3 runner that cannot emit incremental text may send start, then
  done, and remain conformant.
* A client MUST ignore an event name it does not recognise rather than
  aborting. That rule is what lets this list grow without a version bump.
* A Level 2 runner answers this endpoint with 501 and code
  "not_implemented" — never with a single-shot response, which a client
  could not distinguish from a stream that finished instantly. Any verb
  above a runner's declared level is answered the same way.
